# Infogrid Sprint — other Mac / device

Full guide: see **OTHER-DEVICE.md**

Quick path:
1. `git clone https://github.com/hassiddarth-cpu/infogridai.git`
2. Open folder in Cursor
3. Paste contents of `ONE-PROMPT.txt` into Cursor chat
4. Follow agent (Firebase free + Netlify Drop free)
5. Bookmark the Netlify URL on both phones/laptops

After `cloud-config.json` is deployed, new devices can auto-connect.
